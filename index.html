A SMALL GUIDE

작은 공장, 직접 운영해 보세요.

  1. 현장을 살펴보세요.

    트럭·지게차·컨테이너·창고를 누르면 작업·배정 물량·관련 Lot을 볼 수 있습니다. 대상 목록은 키보드로도 선택할 수 있습니다. 지게차의 따라가기를 누르면 카메라가 이동을 추적합니다. 공정 흐름 보기에서는 기존 공정 구역을 선택합니다.

  2. 이상을 발생시켜 보세요.

    ‘수분 이상’을 누르면 같은 원료를 사용한 Lot을 찾고, 미출하 제품의 흐름을 보류합니다.

  3. 근거를 확인하고 조치하세요.

    알림에서 조치 사유를 기록한 뒤 Lot의 보류를 해제할 수 있습니다. 이미 출하한 제품은 영향 추적 대상으로 표시됩니다.

  4. 조건을 바꾸고 보고서를 남기세요.

    운영 속도·기준값을 조정하고 CSV를 가져오거나 보고서를 내려받을 수 있습니다.

시간과 센서는 합성 데이터입니다. 운영 데스크의 요약은 기록·규칙 기반입니다. AI 작업대는 별도의 실제 로컬 모델을 호출하며, 조치는 사람의 확인을 거칩니다. 서버 실행 시 SQLite와 브라우저에 저장합니다. 3D 화면은 포함된 로컬 서버 주소로 열어 주세요. 선반의 상자는 배치 예시이며 실제 Lot 수는 구역 표시와 목록에서 확인합니다.
