# 합성 주문 이행 용어 · 개정 1

이 문서는 학습용 합성 설명이다. 현재 주문 물량은 문서에 기록하지 않으며 get_order_status의 저장 스냅샷과 주문행 배정 기록에서 읽는다.

heldKg는 현재 미출하 보류량이다. shippedImpactKg는 이미 출하된 물량 중 경보에 연결된 영향량이다. 기출하 영향량을 현재 보류량에 더하지 않는다.

readyKg는 차단되지 않은 창고 재고, workInProgressKg는 미출하 공정 물량, unallocatedKg는 Lot 미배정량이다. 이 값은 별도로 읽으며 주문 납기나 실제 출하를 보장하지 않는다.
