1. 생산·검사·주문 기록이 나뉘면 영향을 받는 물량을 찾기 어렵다는 시연 가정에서 출발한다. 첫 장은 긴 회사 설명을 덜어내고 실제 화면의 공장·주문·검사 영역을 확대했다. 전체 화면의 일부 확대임을 캡션에 밝히고, 아래 세 항목을 해당 요소에 화살표로 연결했다.
2. SO-001의 현재 보류 8,400kg, 기출하 영향 4,000kg, 미배정 600kg을 구분한다. 배정을 4,800→3,000kg으로 바꾼 결과를 보여주되 품질 해제나 재고 감소로 설명하지 않는다.
3. 실제 Qwen3 4B/Ollama/LangGraph 연결과 첫 응답의 잘못된 보류 분류를 보완한 사례를 설명한다. 도구 계산과 AI 서술, 단일 사례와 일반 정확도를 구분한다.

합성 데이터 개인 프로젝트다. 실제 우성 시스템·MES·PLC 연동, 현장 요구 조사, 생산성 개선 실적, HACCP 인증을 주장하지 않는다. 사용자는 방향·요구사항·가독성 검토, Codex는 코드·자동 검사·실행 검증을 담당했다.

## 재생성

Windows 맑은 고딕, Python ReportLab·Pillow·PyMuPDF·qrcode가 필요하다. 앱과 PDF 작성 의존성은 구분된다.

```powershell
python -X utf8 docs/portfolio/build_orders_portfolio.py
```

빌더는 1280×720의 3페이지, 버전 PDF·최신 별칭 portfolio.pdf, 전체·100% 미리보기, 링크·글꼴·테두리 좌표 검수 JSON을 만든다. 생성만으로 육안 검수가 완료되는 것은 아니다.

최종 검수는 한국어 텍스트 추출, 3페이지, 본문 경계·겹침, 모든 스크린샷의 바깥 네 변·캡션 분리, 연결선 도착점과 안내의 대응, 색 대비와 최종 렌더링 QR 디코딩을 포함한다. 기존 본문 윤문은 light·변경률 2.27%·게이트 exit 0이었다. v9 연결 문장과 v10 관찰 안내는 별도로 light 경로를 실행해 검증했다. v11의 짧은 설명과 역할 문장은 light·변경률 0%·게이트 exit 0으로 유지했다. 의미 보존은 원문과 별도로 대조했다.

기술 로고의 출처·사용 조건은 [flow](flow/README.md)와 [자산 원장](assets-v8.json)에 있다. Qwen 로고는 공식 조직의 모델 계열 기호이며 후원·회사 연동을 의미하지 않는다.

이전 버전은 당시 구성 이력이다. 최신 자료는 portfolio.pdf와 이름에 생산품질_주문_AI_포트폴리오_v12이 포함된 파일이다. 화면 원본과 승인된 로고 흐름도를 유지하고 PDF 위에 설명을 추가했다. 첫 장의 화면 확대는 PDF의 표시 영역 조정이며 원본 PNG는 수정하지 않았다.

v10은 1쪽의 조작·확인 안내 3개, 2쪽의 보류·기출하 영향·미배정 설명 3개, 3쪽의 기술 역할 설명 4개를 각각 연결선으로 대응시킨다. 2쪽은 미배정 설명을 왼쪽 여백으로 연결해 선 교차를 줄였고, 남은 여백의 선 교차에는 흰색 밑선을 적용해 색별 경로를 구분한다. 주요 UI 글자·버튼은 가리지 않는다.

v11은 첫 장의 긴 문제·회사·역할 문단을 화면 설명으로 대체했다. 실제 화면을 크게 유지하면서 설비를 선택하는 위치, 주문별 물량을 구분하는 위치, 검사값을 대조하고 수동 조치하는 위치를 안내한다. 2쪽의 수량 검증과 3쪽의 오픈소스 AI 흐름·한계 설명은 유지했다.

v12는 모든 장의 핵심 설명 대상 10개를 투명한 사각 테두리로 감쌌다. 화면의 공정·주문·검사 영역, 보류·기출하 영향·미배정 영역, 기술별 로고와 이름을 각각 묶고 테두리에서 설명선을 연결한다. 번호는 테두리 밖에 둔다. 원본 이미지와 본문 문구는 유지했고, 레이아웃 변경만으로 별도 윤문은 실행하지 않았다. 3페이지 렌더링에서 영역 범위·테두리 도착점·주요 글자 가림·바깥 네 변·QR을 확인했다.

3쪽 Python API 설명은 실제 `order_tools.py`와 `agent_backend.py`를 대조했다. 주문 수량 계산은 JS 상태 엔진이 수행하고 Python API는 주문·Lot 기록과 계산 결과를 조회한다. LangGraph는 모델이 선택한 허용 도구를 호출하며 Ollama는 Qwen을 로컬 실행한다. 모델의 자유 서술은 사람의 근거 대조가 필요하다.
